# Bundled skill source

`collar skill` prints the bundled skill source,
[`docs/skills/collar/SKILL.md`](https://git.cmu.dev/ScottyLabs/collar/src/branch/main/docs/skills/collar/SKILL.md).
The installed binary embeds this file; `collar skill install` installs that version without downloading
instructions. See [agent setup](agents.md) for installation and updates.
