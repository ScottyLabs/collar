This catalog describes the feature flags in the canonical [governance repository](https://git.cmu.dev/ScottyLabs/governance), based on its team schema, Terraform configuration, and current Terrier entry. Feature presence enables a family; empty tables use defaults. Secrets below are names only. Collar's `project view` discovers declared features and namespace, but does not resolve secrets, verify applied grants, or provide typed per-feature operations. Existing helper commands are identified where used.

## Safe workflow

1. Run `collar project view -R ScottyLabs/terrier` to inspect declared ownership, features, and secret namespace. The namespace is `terrier` for this repository; set `[project].name = "terrier"` in `secretspec.toml`.
1. For development secrets, declare the required names in the appropriate secretspec profile, then use `collar secrets check` to verify access or `collar secrets set` to set a declared secret, with a reason where required. Collar validates the namespace and declarations before invoking the configured tool; it does not print or resolve secret values itself.
1. Changes to feature flags, membership, provisioned resources, or governance outputs belong in the governance repository and its review/Atlantis workflow. Only team leads may modify other people's memberships. Follow the governance repository's existing validation and PR process; do not apply OpenTofu directly from Collar.
