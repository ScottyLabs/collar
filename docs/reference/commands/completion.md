# `collar completion`

Global options apply to every command below; see the [command index](index.md).

```text
Generate shell completions

Usage: collar completion <SHELL>

Arguments:
  <SHELL>
          [possible values: bash, elvish, fish, powershell, zsh, nushell]

Options:
  -h, --help
          Print help (see a summary with '-h')

Examples:
  collar completion bash
  collar completion nushell

Save or source the generated script using your shell's completion setup. Regenerate it after updating Collar.
```
