# `collar infra`

Global options apply to every command below; see the [command index](index.md).

```text
Inspect canonical infrastructure and build pinned Nix configurations

Usage: collar infra <COMMAND>

Commands:
  check            Evaluate the infrastructure flake and build its declared checks
  build            Build one declared host's system closure locally
  atlantis-config  Build the Atlantis configuration generated by the infrastructure flake
  hosts            List declared infrastructure host configurations
  service          Find the source configuration for a service across hosts
  help             Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help (see a summary with '-h')

Examples:
  collar infra hosts
  collar infra service kennel
```

## `collar infra check`

```text
Evaluate the infrastructure flake and build its declared checks

Usage: collar infra check [OPTIONS]

Options:
      --checkout <CHECKOUT>
          Use a local infrastructure checkout, including uncommitted changes

          [env: COLLAR_INFRASTRUCTURE]

      --offline-source
          Read the last verified canonical source snapshot and keep Nix offline

  -h, --help
          Print help
```

## `collar infra build`

```text
Build one declared host's system closure locally

Usage: collar infra build [OPTIONS] <HOST>

Arguments:
  <HOST>
          Host name from modules/systems.nix

Options:
      --darwin
          Build a nix-darwin configuration instead of a NixOS configuration

      --checkout <CHECKOUT>
          Use a local infrastructure checkout, including uncommitted changes

          [env: COLLAR_INFRASTRUCTURE]

      --offline-source
          Read the last verified canonical source snapshot and keep Nix offline

  -h, --help
          Print help
```

## `collar infra hosts`

```text
List declared infrastructure host configurations

Usage: collar infra hosts [OPTIONS]

Options:
      --checkout <CHECKOUT>
          Inspect local infrastructure changes instead of the latest canonical revision

          [env: COLLAR_INFRASTRUCTURE]

      --offline
          Read an existing snapshot without refreshing it

      --json [<FIELDS>]
          Output selected JSON fields (comma-separated); omit fields for all

  -h, --help
          Print help
```
