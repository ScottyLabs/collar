# Infrastructure workflows

`collar infra` runs local Nix workflows against the latest canonical Infrastructure revision. The canonical source snapshot only identifies files and revision; Nix evaluates the full repository through a flake reference pinned to that revision. Pass `--checkout PATH` to evaluate a local tree, including uncommitted changes. Pass `--offline-source` to use Collar's last verified source snapshot and pass Nix's `--offline` flag, which also requires Nix to have its flake inputs cached. Each operation requires Nix and forwards its output and exit status.

- `collar infra check` runs `nix flake check`.
- `collar infra build HOST` builds a declared NixOS host's system closure with `nix build --no-link`. Use `--darwin` for a nix-darwin host.
- `collar infra atlantis-config` builds the flake's `.#atlantis-yaml` output, the manifest generated by the Atlantis workflow.
- `collar infra colmena --checkout PATH -- ARGS...` runs the installed Colmena from the checkout's devenv shell. Colmena applies remain explicit through the arguments after `--`.

The infrastructure flake declares a Colmena hive for NixOS and Darwin hosts. These workflows do not apply configurations, connect to hosts, or run Terraform/OpenTofu plans or applies. Atlantis remains the established path for Terranix PR plans and applies.
